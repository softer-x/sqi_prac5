# AI Music Recommendation Agent

## Идея
Музыкальный ИИ ассистент - ассистент, который анализирует эмоциональное состояние пользователя и подбирает персонализированные музыкальные композиции для психологической поддержки и настроения. 

## Возможности
- Анализ эмоционального состояния человека
- Интеллектуальный подбор музыки
- Персонализация рекомендаций
- Работа с API Яндекс.Музыка (в случае онлайн-модели с Hurated API) позволяет подбирать актуальные доступные треки
- Предоставляет структурированную информацию о каждом треке: альбом, жанр, длительность, ссылки для прослушивания
- Позволяет искать отдельные треки в Яндекс.Музыке (в случае Hurated API)

## Установка и сборка
Для сборки необходима установка библиотеки:
```
pip install yandex-music
```
Если данный способ не работает, можно попробовать альтернативный:
```
python3 -m venv music_venv
source music_venv/bin/activate
pip install yandex-music
```
Далее:
```
git clone <ваш репозиторий>
cd music-agent
mkdir build && cd build
cmake ..
make -j
```
Для работы ИИ-агента требуется токен сервиса Яндекс.Музыка, о том, как его получить, можно почитать здесь (есть много разных способов): https://yandex-music.readthedocs.io/en/main/token.html

Документация по библиотеке yandex-music: https://yandex-music.readthedocs.io/en/main/index.html

## Доступ к локальной модели
```
git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp
cmake -B build -DCMAKE_BUILD_TYPE=Release 
cmake --build . --config Release -- -j$(nproc)
```

## Настройка config.json
```
{
    "mode": "hurated",
    "hurated": {
        "host": "ai-api.hurated.com",
        "port": "443",
        "api_key": "укажите ваш ключ"
    },
    "local": {
        "backend": "llama.cpp",
        "model_path": "укажите полный путь к модели, которую скачали",
        "llama_cli_path": "укажите полный путь к llama-cli",
        "context_length": 4096,
        "threads": 4,
        "temperature": 0.7
    },
    "music": {
        "yandex_music_token": "укажите ваш токен в яндекс-музыке. Если используете только локальную модель, можете пропустить этот этап",
        "python_path": "укажите полный путь к environment, куда устанавливали yandex-music",
        "music_script_path": "yandex_music_client.py"
    }
}
```

## Запуск:
Для запуска с режимом из config.json выполните команду:
```
./music_ai_agent
```
Для запуска с выбором режима выполните команду
```
./music_ai_agent --local
```
для локальной модели и
```
./music_ai_agent --hurated
```
для онлайн.

Доступны два режима работы агента: --suggest и --find
